# Example Experiment

No real exported experiment was present when the portfolio polish pass was prepared.

To create a curated example:

1. Open the simulator.
2. Go to `EXPERIMENTS`.
3. Select `House Layout`.
4. Select `A*`, `Dijkstra`, and `RRT*` only if the runtime planner exists in your checkout.
5. Run 3-5 repetitions with seed `42`.
6. Open `EXPERIMENT RESULTS`.
7. Click `EXPORT DATA`.
8. Copy one clean exported folder into `experiment_results/example/`.

Do not fabricate CSV or JSON values. This folder should contain only real measured simulator output.
